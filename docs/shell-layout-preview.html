我先看一下 release workflow 和最近的 tag 记录。

读取 .github/workflows/release.yml 完成
on:push.tagsworkflow_dispatch concurrency: release-${{ github.workflow }}

问题在触发条件叠加：push.tags 和 workflow_dispatch 都会进入同一个 job，而 concurrency 只按 workflow 名分组，没有按 ref 区分。

  • 给 concurrency.group 加上 github.ref，让 tag 与手动触发互不取消。
  • 把 workflow_dispatch 的输入校验提前，避免空 tag 也走发布分支。
建议补丁 release.yml 待审阅
