## 2. 关键决策记录

1. **dev 跨源问题**：daemon 无 CORS/OPTIONS 处理。试过 webRequest 注入（导致 fetch 永久挂死，已回退）、vite proxy（`/qaqh-daemon` 代理，代码仍在 vite.config.ts 可用）。**当前方案：dev 下 `webSecurity: false`（仅 dev，生产 file:// 同源无此问题）+ 直连 daemon endpoint**。
2. **Solid 2 rc.6 API 陷阱**（与 cheatsheet 的差异都在代码里体现）：
   - `produce` 不存在——store setter 直接收 draft 函数 `setState(s => {...})`
   - store setter **无 path 形式**——一切走 draft
   - 错误边界叫 `Errored`（solid-js 导出），不是 ErrorBoundary
   - 事件用 `onKeyDown`/`onInput`（DOM 原生 casing）
   - **reads lag writes**：同一 tick 内 setState 后读 store 是旧值——所有存在性守卫必须放 draft 回调内部（tabs.ts 已全部照此改）
3. **`session.list` 返回 `SessionMeta[]`**（qaqh-types/session.rs）：seed/title/cwd/mode(u8: 0=code,1=plan)/archived/ephemeral/last_summary 等，非 SDK bindings 类型（后端未导出 ts-rs）。

## 3. 🔴 遗留 P1：冷启动首帧 transcript 空白

**现象**：全新启动后，tabs/statusline/composer 正常，projection 数据完整（rev/turns/hydrated 全部就绪），但 transcript 渲染空态 fallback；**对 App.tsx 做任意 HMR 触发（重执行组件）后立即渲染 8 turns**。

**已排除**（都验证过，不要重查）：
- ❌ 网络层：bootstrap/timeline 请求成功，proxy/直连 curl 全通
- ❌ 数据层：projection.sessions 有全部数据（CDP 直读确认 rev/turns=8）
- ❌ store 写入时序（reads-lag-writes）：守卫已在 draft 内
- ❌ vite 模块分叉：curl 确认单 URL 无 `?t=`；`--force` 重优化无效
- ❌ Solid 双实例（未完全排除但高度可疑，见下）

**最强嫌疑**：跨模块边界的信号订阅断链。曾测得 `import('/src/lib/client.ts').projection !== import('/src/state/session.ts').projection`（sameProj=false），但 serve 源里两处 import URL 完全一致——疑似 vite dev 下 client.ts 被 SDK 的 `/@fs/` 依赖链或优化器分叉。**当前代码（未提交验证）已把桥改为纯 Solid store 镜像**（session.ts：projection.subscribe → reconcile 到 createStore，组件只读 store），设计上消除了外部存储订阅，**很可能已修复但未来得及冷启动验证**。

**下一步**（建议顺序）：
1. `pkill -f electron; pkill -f vite` 后 `npm run dev` 冷启动，等 60s，CDP 查 `document.querySelectorAll('.turn').length`
2. 若仍为 0：在 `session.ts` 的 `syncFromProjection` 里加 `console.info` 确认 subscribe 回调触发；再在 Transcript 里加 mount/effect 日志定位断点
3. 若 store 镜像方案仍失败，Plan B：App 里把 `useSession` 的调用挪进 `onSettled` 之后用显式 `createSignal(dataVersion)` 驱动
4. 附带修：StatusLine 的 lease 显示已改（TTL 归零后显示 "lease renew…"，sid 稳定即续期正常——已验证 renew 实际工作）

**调试基建**（都已就绪可复用）：
- Electron 以 `REMOTE_DEBUGGING_PORT=9333 npx vite` 启动后，`/tmp/cdp5.mjs <wsUrl> "<js>"` 可在页面执行 JS（wsUrl 从 `http://127.0.0.1:9333/json/list` 取 `webSocketDebuggerUrl`）；`/tmp/cdp-log2.mjs` 抓 console；`/tmp/cdp-type.mjs`/`cdp-enter.mjs` 发 isTrusted 输入（**合成 dispatchEvent 不会被 Solid 受控输入接受，必须用 Input 域**）
